# 상태 전환 어휘 (조사·브레인스토밍)

작성: 2026-08-07 · 갱신: 2026-08-10  
목적: 구현이 아니라 **전환 메타포 목록**을 모아 두고, 컨트롤마다 맞는 말을 고르기 위함.  
기준 사례: 아르카나(장·단 **Z축 180° 회전**). 전부에 회전을 강요하지 않는다.

원칙 한 줄: 상태는 점프(on/off 클래스 교체)하지 않고 **시간을 가진 전환**으로 바뀐다. why 없는 motion은 스타일링이다. 소리(어택/릴리즈·PLAY/STOP)도 같은 축이다.

### 성격 경계 (Realm)

값이 여러 개여도 **성격이 크게 바뀌는 경계**는 같은 순회에 묻지 않는다.

- 선례: **Maj 안 순회 / Min 안 순회 / dim 순회 분리** — 퀄리티 영역이 바뀌면 인지가 바뀌어야 함.
- **재료 활성 ↔ 비활성** (`null`/∅, `rest`)은 활성 상태에서 프리셋이 순회되더라도 **다른 축**. 비우기는 ∅만 (활성 사이클에 rest/empty를 넣지 않음).
- **영역 안**: 같은 성격의 변형 → 약한 피드백 (디텐트·펄스).
- **영역 넘김**: 활성↔비활성, 극성(장↔단), (예전의) maj↔min↔dim 영역 → **다른 전환 언어**로 인지 (점등/소등, 아르카나, 스탬프…).

UI 선택(`.on`)·기기 armed(metro/play)와 **재료 presence**를 섞지 않는다.

### 기계 섀시 (Chassis) — 서비스 기본 정책

OneSheet는 **한 대의 물리 기계**다. Pocket Operator처럼 **격자와 존은 고정**이고, 모드(렌즈)는 그 키의 **뱅크/페이지**다.

| 절대 유지 | 모드로 바뀌어도 됨 |
|-----------|-------------------|
| 4×4 기하 · 슬롯 수 · 존 배치 | 각 패드의 **매핑**(무엇을 쓰는지) |
| LCD · transport · 기기 실루엣 | 점등 · armed · 라벨 · 잉크 |
| 만지는 표면이 사라지지 않음 | transport 모드 래치 (어느 렌즈인지) |

- ❌ 모드마다 다른 화면·마법사 단계·패널 flip/와이프로 **레이아웃이 바뀌는** 전환  
- ❌ 격자 크기·패딩·존 구조가 모드에 따라 재배치  
- ✅ **같은 16키** 위에서 LED·라벨만 재매핑. transport가 어느 뱅크인지 말한다.  
- ✅ 모드 전환 피드백 = **래치 점등 + 패드 재매핑** (기계가 페이지를 바꾼 느낌). 면 뒤집기가 아님.

리듬 브러시 행 등 **모드 전용 악세서리**가 필요하면: 새 페이지가 아니라, 섀시에 예약된 슬롯으로 **상승·래치**한다 (격자 자체는 不动).

## 모드 전환 트랜지션 초안 (채택 방향)

목표: **같은 기계가 뱅크를 바꾼다.** 레이아웃은 不动, 인지 변화는 불과 잉크로.

### A. Transport 래치 (주 신호)

- GRID / DEG / RHY 중 **하나만** latched (`.on`).
- 이전 모드: `--dur-armed`로 소등(언래치).
- 새 모드: 같은 시간으로 점등(래치).
- why: PO에서 “지금 어떤 기능 페이지인지”는 **키 옆/기능 LED**가 말한다. 격자를 뒤집지 않는다.

### B. 패드 LED·잉크 재매핑 (본체)

같은 16칸, 같은 자리. 모드가 바뀌면:

1. **짧게 딤** (~80–120ms, `--ease-presence`) — 이전 뱅크 불이 한 호흡 꺼짐.  
2. **새 라벨·점등 패턴 페이드 인** (`--dur-presence`) — 차트 심볼 / DEG 도구 / 리듬 셀이 **같은 키 위**에 찍힘.

구현 힌트: 격자 DOM·CSS grid는 유지. 셀 내용만 크로스페이드(또는 딤→교체→페이드).  
❌ `pad-stage` 전체 flip, 슬라이드 아웃, 그리드 재배치.

### C. 모드 악세서리 (리듬 브러시 등)

- 브러시 행은 **새 화면이 아님**. 섀시 아래 예약 슬롯.
- RHY 진입: 슬롯으로 **상승·래치** (높이/opacity, `--dur-armed`).
- RHY 이탈: **하강·소등**.
- 격자가 밀리거나 리플로우로 “다른 앱”이 되면 실패. 가능하면 슬롯 높이를 예약해 점프를 줄인다.

### D. (선택·2차) 스캔 펄스

- 모드 진입 직후 한 줄/한 칸 **아주 짧은 LED 스윕** (~120–180ms).
- “기계가 페이지를 받았다” 디텐트.  
- 과하면 장식 → 기본은 A+B만. D는 시제품에서 强弱 조절.

### E. 하지 않을 것

| 금지 | 이유 |
|------|------|
| Y-flip / 카드 flip of pad-stage | 다른 면 = 다른 기기 |
| 전체 와이프·페이지 푸시 | 앱 화면 전환 |
| 모드별 다른 그리드 크기 | 섀시 붕괴 |
| OP-1식 “통째 다른 세계” | OneSheet 모드는 뱅크이지 여행이 아님 |

### 타이밍 초안

| 단계 | 시간 | 토큰 |
|------|------|------|
| transport 래치 | ~0.28s | `--dur-armed` |
| 패드 딤 | ~0.08–0.12s | `--ease-presence` |
| 잉크·점등 인 | ~0.22s | `--dur-presence` |
| 브러시 상승 (해당 시) | ~0.28s | `--dur-armed` |
| 스캔 펄스 (선택) | ~0.15s | 1회 |

소리: 모드 전환은 **뮤트하지 않는다**. 재생 중에도 뱅크만 바뀌고 루프는 이어짐 (시간과 소리를 나누지 않음).

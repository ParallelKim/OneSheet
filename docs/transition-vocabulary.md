# 상태 전환 어휘 (조사·브레인스토밍)

작성: 2026-08-07  
목적: 구현이 아니라 **전환 메타포 목록**을 모아 두고, 컨트롤마다 맞는 말을 고르기 위함.  
기준 사례: 아르카나(장·단 **Z축 180° 회전**). 전부에 회전을 강요하지 않는다.

원칙 한 줄: 상태는 점프(on/off 클래스 교체)하지 않고 **시간을 가진 전환**으로 바뀐다. why 없는 motion은 스타일링이다. 소리(어택/릴리즈·PLAY/STOP)도 같은 축이다.

---

## 1. 공간 / 입체

| 전환 | 감각 | 잘 맞는 축 | 메모 |
|------|------|------------|------|
| **Y-flip** (세로축, 좌우 문짝) | 앞·뒷면이 두께를 갖고 바뀜 | 렌즈·모드 한 쌍 (A/B면) | 아르카나(Z)와 다름. 카드/카메라 flip에 가까움 |
| **X-flip** (가로축, 상하 플랩) | 덮개·폴더 | 열림/접힘, 상세 펼침 | |
| **Z-rotate 180°** | 같은 면의 극성 | 장/단 등 양극 | **아르카나** — 이미 채택 |
| **힌지 / 도어** | 축이 한쪽에 고정 | 패널·서랍형 | |
| **페이지 넘김** | 순서·히스토리 | 프리셋 순회(약하게) | |
| **코인 플립** | 예측 불가→착지 | 랜덤류 | OneSheet에는 약함 |

## 2. 병진 / 가림

| 전환 | 감각 | 잘 맞는 축 | 메모 |

## 3. 점등 / 에너지

| **블룸 / 글로우 업** | 에너지 충전 | PLAY armed | TE 느낌 — 과하면 글로우 장식 |

## 레퍼런스 (훔칠 것 / 안 훔칠 것)

### Teenage Engineering
- **OP-1**: 모드가 화면을 **통째로 점유**. 전환 = 컷보다 *다른 세계로 넘어감*. 테이프 릴·레벨 바운스 = **기계가 도는** 피드백.  
  https://teenage.engineering/guides/op-1  
  https://blakecrosley.com/guides/design/teenage-engineering
- **Pocket Operator**: 4×4 그리드 **LED = 상태**. write는 점등/아이콘으로 armed. 장식 애니보다 **불이 말함**.  
  https://teenage.engineering/guides/po-faq/en
- **OP-Z app**: camera **flip** 토글 — 이름 그대로 축 flip 메타포.  
  https://teenage.engineering/guides/op-z/app

### Nothing
- **모노톤 + 포인트**: 흑·백이 구조, 포인트 색/Glyph 빛이 **활성·알림·한 신호**만 담당.  
  OneSheet 점등·재료 presence와 같은 축. 팔레트 복제가 아니라 **운용**을 훔친다.
- https://nothing.tech  
  https://design-milk.com/the-nothing-phone-3s-glyph-matrix-turns-notifications-into-pixel-art/
- 상세: `docs/design-references.md`

### 일반 UI (사무 스위치)
- Apple HIG / Material 토글: thumb **슬라이드**, 즉시 적용.  
  악기·장난감 UX에 그대로 쓰면 너무 설정 앱이 되기 쉽다. **어휘 후보일 뿐 기본값은 아님.**

### 하드웨어 공통
- 런치패드: **프레스 + 점등** 조합.
- 로커/시소, 플런저, 디텐트 엔코더 — 물리 부품 이름이 곧 전환 이름.

## Teenage Engineering

배울 것: 소수 모드(렌즈), 색=매핑, 적은 조작+한 겹, 존, 친숙한 메타포, 즉시 반응.  
안 배울 것: 모드를 마법사 단계로 쪼개기, 장식 글로우로 “테크” 흉내, OP-1식 “통째 다른 세계”로 모드 화면을 갈아치우기.

- **PO (기본):** 4×4 **고정 섀시**. 뱅크/기능이 바뀌어도 같은 16버튼. LED가 상태·armed를 말함.  
  → OneSheet 모드(GRID/DEG/RHY) = 같은 키의 페이지. 레이아웃 전환 아님.
- OP-1 / OP-Z — 기계 피드백·점등 어휘만 참고. 전체 면 flip은 모드에 쓰지 않음.  
  상세: `docs/transition-vocabulary.md`

## Nothing

배울 것: **모노톤 바탕 + 포인트 컬러(및 Glyph 점등)로만 상태를 말한다.**  
흑·백(그레이)이 대부분을 담당하고, 강조·활성·알림은 **한 점의 색/빛**에 맡긴다.  
UI가 로고처럼 읽히게 — 장식 레이어를 쌓지 않는다.

안 배울 것: 투명 하드웨어 복제, 레인보우 테마, Glyph를 장식 네온으로만 쓰기.

포인트 컬러 / 점등이 OneSheet에 붙는 자리 (후보):
- 재료 **활성** (hit, 채운 슬롯)
- 기기 **armed** (metro, playing)
- 포커스·에러 등 **한 번에 하나**만 말하는 신호

참고:
- https://nothing.tech
- Glyph / 모노 OS 방향 — 빛이 화면을 대체하는 알림 언어  
  https://design-milk.com/the-nothing-phone-3s-glyph-matrix-turns-notifications-into-pixel-art/
- 팔레트: 흑·백 + (전통적으로) 레드 포인트 — 복제 의무 없음, **운용 방식**만

## 공통 규칙

1. 모노가 먼저다. 포인트는 **축이 바뀔 때만**.
2. 포인트 색을 두 개 이상 동시에 쓰지 않는다 (한 문장·한 신호).
3. **영역 넘김**(활성↔비활성, 극성 전환)과 **영역 안 순회**를 같은 피드백으로 취급하지 않는다.
4. **섀시 고정:** 모드가 바뀌어도 격자·존·실루엣은 不动. 바뀌는 것은 매핑·점등·라벨.
5. why를 색/빛으로 설명 못하면 → 스타일링. 뺀다.
